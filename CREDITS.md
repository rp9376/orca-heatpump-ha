# Credits

## orca-energy-ha

This project is a rewrite inspired by, and partly derived from,
**[orca-energy-ha](https://github.com/Tomasinjo/orca-energy-ha)** by
**Tom Kern ([@Tomasinjo](https://github.com/Tomasinjo))**, 2022–2026.

orca-energy-ha did the protocol and tag research this rewrite builds on:
finding the display's HTTP interface with Wireshark, reading the touch
project's tag definitions over FTP, dumping tag values from real pumps and
mapping the touch menus to tags. The tag names, value encodings and much of
the catalog here come from that work. It is used under the MIT license; its
notice is kept in [LICENSE](LICENSE).
